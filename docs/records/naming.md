# Naming

November 2026. Decision: the name is Bica, at `bica.sh`, with no second name.

## Before

The product was already Bica, a Lisbon espresso. The repo, the package, and the domains `vaibica.com` and `vaibica.dev` used a second name, `vaibica` ("Vai Bica", go, Bica!), because the plain name's domains seemed taken. Two names for one thing was the cost.

## Other products named Bica or Bika

- Bika.ai is the biggest: over $10M raised, sold as a messenger for AI agents, and it sounds the same as Bica. Since 2026-04-04 it is in limited maintenance while its company moved to a new product, Buda.
- Fladov's Bica is an AI business assistant for small businesses in Nigeria, with a v2 in May 2026. It is a different market.
- BicaMind Labs' FuguNano is a small coding-loop repo.
- Bica for Figma is a UI kit.

None of them is well known enough to matter.

## Domains

On Cloudflare, `.com`, `.dev`, `.ai`, and `.app` were not available. These were: `bica.sh`, `bica.chat`, `bica.build`, `bica.run`, `bica.cafe`, and `bica.engineer`.

`.sh` is Saint Helena's country domain, used by developer tools because it reads as "shell": brew.sh, astral.sh, charm.sh, and bun.sh before bun.com. UI products use it too: cursor.sh before cursor.com, polar.sh, and dub.sh. Its cost is a hint of a command-line tool, while Bica is a UI. It also makes an install command short: `curl -fsSL bica.sh | sh`.

`bica.chat` was the runner-up. `conductor.build`, a Mac app for parallel coding agents in worktrees, is a close peer on `.build`.

## Decision

Bica, at `bica.sh`. `vaibica` goes away, its domains included, with no redirects: the repo is `cyrillbrito/bica`, and the root package is `bica`, a name not taken on npm.
