# Omnigent

From https://omnigent.ai. Kind: a meta-harness more than an orchestrator. It wraps Claude Code, Codex, Pi, or your own agents in one session format, and a server adds policies, shared history, and clients for terminal, web, app, mobile, and a REST API.

- Built-in multi-agent setups: Polly, a coding orchestrator, and Debby, a debate between models. You write your own in YAML.
- Policies outside the prompt: spend caps, model routing, and asking a person before risky actions.
- Sandboxes on the machine or in the cloud, limiting files and network, with credentials passed without showing them to the agent.
- Live sessions shared by URL, where others can read, comment, and steer.

For Bica, a spend cap per session and a debate between two models are the ideas worth a look. Sharing with a team is out of scope.
