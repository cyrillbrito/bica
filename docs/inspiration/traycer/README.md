# Traycer

From https://traycer.ai. Kind: orchestrator, started as a planning tool. A desktop app that runs 22 agents side by side, each in its own worktree.

- Agents message each other to ask questions, request reviews, and hand off work across chats.
- Each task has shared specs, tickets, artifacts, and history, and the model can change mid-chat.
- Built-in skills for planning, debugging, reviewing, debating, documenting, and splitting work into tickets.
- Shared workspaces where teammates comment on artifacts and steer.

For Bica, a spec or plan that several sessions of one task share is the idea to look at.
