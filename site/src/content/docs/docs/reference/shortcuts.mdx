Every shortcut in Bica, grouped by where it works. ⌘/ lists the global ones inside the app, and the [command palette](/docs/basics/command-palette/) shows each action's shortcut on its row.

Keys are given for the Mac. On Linux and Windows, ⌘ is Ctrl and ⌥ is Alt, and Bica takes either ⌘ or Ctrl for every ⌘ shortcut on any system. ⌃ means the Control key everywhere. The palette shows the Mac symbols on every system.

## Anywhere

These work on every page, even while you type in the composer or a terminal.

| Keys | What it does |
| --- | --- |
| ⌘K | Opens or closes the command palette. |
| ⌘/ | Lists every shortcut, in the palette. |
| ⇧⌘O | Starts a new session in this page's workspace. The browser keeps ⌘N for new windows. |
| ⌥⇧↓ | Opens the next session that needs you. Press again to move on. |
| ⌃\` | Opens a terminal in this page's workspace. |
| ⌘B | Shows or hides the sidebar. |
| ⌥⌘B | Shows or hides the side panel. |
| Esc | Closes the open file or diff and goes back to the session. On a phone, closes the sidebar. |

## Command palette

| Keys | What it does |
| --- | --- |
| ↑ ↓, or ⌃P ⌃N | Moves through the list. |
| Enter | Runs or opens the highlighted row. |
| Backspace in an empty box | Goes back from a second page. |
| Esc | Goes back, or closes the palette. |

## Composer

| Keys | What it does |
| --- | --- |
| Enter | Sends. While the agent works, the prompt joins the current run. |
| ⌘Enter | Sends. While the agent works, queues the prompt for the next run instead. |
| Shift-Enter | Adds a new line. On a phone, Enter adds one too, and the send button sends. |
| Esc Esc | Stops the run. Press Esc twice within half a second. |
| ↑ at the very start | Steps back through the prompts you sent. |
| ↓ at the very end | Steps forward again, back to your draft. |
| Backspace after `[Image #1]` | Removes the marker and its image together. |

While you edit a prompt held for tonight, Enter adds a new line. See [Prompting](/docs/basics/composer/) for steering and the queue.

## Questions from the agent

When a session [asks you a question](/docs/features/tools/#the-agent-can-ask-you-questions), these work inside the question card, or when nothing else has focus.

| Keys | What it does |
| --- | --- |
| 1 to 9 | Picks that option. |
| ⌘Enter | Sends your answers. |

## Project menu

The menu under the composer on the start screen, where you pick the project a new session works in. Typing searches the projects.

| Keys | What it does |
| --- | --- |
| ↑ ↓, or ⌃P ⌃N | Moves through the list. |
| Enter | Picks the highlighted project. |

## Sidebar

| Keys | What it does |
| --- | --- |
| ⌘-click | Adds a session to the selection, or takes it out. |
| Shift-click | Selects a range. |
| Esc | Clears the sidebar's selection. |
| ← → on a column's edge | Resizes the column, once the edge has focus. |

## Replies and Git

| Keys | What it does |
| --- | --- |
| Click a path in a reply | Opens the file in Bica. |
| ⌘-click a path | Opens the file in your editor. |
| ⌥-click a path | On a Mac, shows the file in Finder. |
| ⌘Enter in the commit box | Commits. With the box empty and a fast model set, the message is written for you. |

## Terminal

A terminal passes every key to its shell, except the ones under [Anywhere](#anywhere). On a phone, a key bar above the keyboard adds Esc, Tab, ^C, and the arrows. See [Terminals](/docs/basics/terminals/).
