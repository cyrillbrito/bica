Bica only listens on the machine it runs on. To follow your sessions from your phone or a second computer, give it an address on [Tailscale](https://tailscale.com), a free private network between your own devices.

```d2 title="The phone reaches bica through Tailscale, which passes it on to localhost"
direction: down
phone: Phone {class: browser}
machine: Your dev machine {
  ts: tailscale serve
  bica: bica {class: focus}
  ts -> bica: "localhost:3141"
}
phone -> machine.ts: "HTTPS, inside your tailnet"
```

Only devices signed in to your Tailscale account can reach that address. Nothing is opened to the internet.

<Steps>

1. Install Tailscale on the machine that runs `bica` and on your phone, and sign in to the same account on both.

2. On the machine that runs `bica`, give Bica an HTTPS address:

   ```sh
   tailscale serve --bg --https=3141 http://localhost:3141
   ```

   If HTTPS isn't turned on for your tailnet yet, the command prints a link to turn it on. Open it, then run the command again.

3. Find the address:

   ```sh
   tailscale serve status
   ```

   It looks like `https://<machine>.<tailnet>.ts.net:3141`.

4. Open that address on your phone. You see the same sessions as on the laptop, updating live.

   <Image src={sessionPhone} style={{ maxWidth: '16rem' }} alt="A session on a phone: the transcript fills the screen, with the composer at the bottom and buttons for the sidebar and side panel in the top bar" />

</Steps>

Tailscale keeps this setting across reboots, so from then on only `bica` has to be running. If you start `bica` with `--port`, use that port in both places.

## Install it as an app

Bica can sit on your home screen or Dock with its own icon and window. The icon shows a badge with the number of sessions that need you.

- On an iPhone or iPad, open the address in Safari, tap Share, then Add to Home Screen.
- On Android, open it in Chrome, then pick Add to Home screen or Install app in the ⋮ menu.
- On a computer, use the install icon in the address bar of Chrome or another Chromium browser, or File → Add to Dock in Safari on a Mac.

The app needs the HTTPS address from `tailscale serve`, and so do [voice calls](/docs/features/voice/), which use the microphone. Installing on the phone still has rough edges.

## Keep it private

:::danger[Never use tailscale funnel]
`tailscale funnel` puts the address on the public internet. Bica has no login and its agents run commands on your machine, so your tailnet is the only thing keeping others out.
:::

To take the address away again, run `tailscale serve --https=3141 off`.
