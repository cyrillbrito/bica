An artifact is a report page an agent builds for you: a dashboard, a comparison, an explainer with charts and tables. Ask for one when the answer is easier to see than to read, or when you want to keep it and have it updated later. "Make a report of last quarter's sales" is enough.

## Find and open them

Artifacts sits at the top of the sidebar. It lists every artifact, newest first, with its title and when it last changed. Pick one to read it full page.

The top bar has a theme picker and three light and dark buttons: Match Bica, Light, and Dark. Your picks stay on this device and apply to every artifact.

- Bica uses the app's own colors and fonts.
- Paper is calm and bookish, for long reading.
- Dashboard is bold and dense, with bright chart colors.

Charts and tables change with the theme, since agents don't pick colors themselves.

While an agent works on an artifact, the open page reloads each time the file changes and keeps your place. In a session, the step where the agent wrote it has an Open button, and the file's path in a reply opens it too.

## Update one

Artifacts don't belong to a project or a session, so any session can change any of them. Ask by name, as in "add September to the sales report", and the agent finds the file and edits it instead of making a new one.

## Share one

The download button saves the artifact as one HTML file in the theme you picked. It works offline, in any browser, with no Bica behind it, so you can send it to someone or keep it with a project.

Artifacts are files in Bica's data folder, in `artifacts/`, one HTML file each. Rename or delete them there. The pages run in a sandbox, so a page can't reach your sessions or files.
